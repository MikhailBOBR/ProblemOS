# ProblemOS / Решатор

ProblemOS - система ведения бытовых проблем до результата: дело, факты, доказательства, документы, дедлайны, следующий шаг и административное управление шаблонами.

Первый слой проекта сделан самодостаточным, без внешних зависимостей. Его можно запускать напрямую через Node.js, чтобы быстро развивать продуктовую логику до перехода на большой стек вроде Django + DRF + Next.js.

## Быстрый старт

```powershell
node server/src/index.js
```

Открой:

```text
http://127.0.0.1:8080
```

Демо-аккаунты создаются автоматически при первом запуске:

```text
admin@problemos.local / admin123
demo@problemos.local  / demo123
expert@problemos.local / expert123
```

## Проверка

```powershell
node --test server/tests/*.test.js
```

## Что уже есть

- регистрация и вход;
- роли пользователя и администратора;
- категории: возврат товара, ЖКХ, некачественная услуга;
- создание дела из свободного описания;
- AI-like классификация и извлечение фактов на правилах;
- маршруты дела, статусы, следующий шаг;
- загрузка доказательств через web-интерфейс;
- хранение файлов доказательств на диске с SHA-256 и защищенным скачиванием;
- workflow-действия по делу: шаг выполнен, отправлено, срок нарушен, эскалация, закрытие;
- генерация документов по шаблонам;
- экспорт документов в RTF/DOCX/PDF;
- ZIP-пакет дела с документами, audit log и файлами доказательств;
- проверка полноты дела перед документом;
- комментарии по делу;
- фильтры дел и админские списки пользователей/дел;
- пакет дела в Markdown;
- уведомления и дедлайны;
- базовая админка шаблонов и статистики;
- Telegram webhook skeleton: `/newcase`, `/mycases`, `/next`.
- профиль пользователя с привязкой Telegram ID;
- audit log системных действий по делу;
- deadline scheduler и read/unread уведомления;
- Telegram dispatch для дедлайнов через `TELEGRAM_BOT_TOKEN`;
- diagnostics, JSON export, backup;
- Dockerfile и docker-compose.

## Операционные команды

```powershell
node server/src/jobs/deadlineScheduler.js
```

```powershell
$env:TELEGRAM_BOT_TOKEN="..."
node server/src/telegram/pollingRunner.js
```

Docker:

```powershell
docker compose up --build
```

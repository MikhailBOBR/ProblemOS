# ProblemOS Project State

Дата старта: 2026-05-12

## Текущий этап

Этап 1 + первый вертикальный MVP-срез.

Мы не просто пишем CRUD. Фокус первого слоя: пользователь может описать бытовую проблему, получить структурированное дело, увидеть следующий шаг, загрузить доказательства и сформировать документ.

## Сделано в этом шаге

- Выбран самодостаточный стартовый стек без внешних зависимостей: Node.js HTTP API + статический web-интерфейс + JSON storage.
- Зафиксированы продуктовые категории MVP.
- Собран API для пользователей, дел, доказательств, документов, уведомлений и админки.
- Добавлен web-кабинет.
- Добавлены тесты основного пользовательского сценария.

## Ближайший следующий шаг

Этап 2. Усилить backend-модель:

1. Вынести JSON storage на PostgreSQL-compatible слой или подготовить Prisma/Django schema.
2. Добавить полноценные файлы evidence на диск с безопасным хранилищем и проверкой типов.
3. Добавить расширенный workflow engine: переходы статусов, автоматические события таймлайна, правила дедлайнов.
4. Подготовить Telegram-бота к реальному polling/webhook.

## Принцип развития

Каждый следующий шаг должен оставлять проект запускаемым. Большие модули добавляем вертикальными срезами:

```text
domain -> API -> UI -> tests -> docs
```

## Архитектурная цель

Финальная версия может быть мигрирована в:

```text
Frontend: Next.js + TypeScript
Backend: Django + DRF или NestJS
DB: PostgreSQL
Storage: S3/MinIO
Bot: aiogram или Telegraf
Queue: Redis + Celery/BullMQ
AI: OpenAI-compatible provider через отдельный AI layer
```
